# Pingyu's Garden

花萍雨的个人数字花园。这个站点优先服务我自己，作为长期维护的个人入口，其次才服务简历展示。

## 页面结构

- `/` 首页花园入口
- `/profile` 个人介绍
- `/projects` 项目
- `/articles` 文章
- `/tools` 小工具

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 说明

- 首页采用中心头像 + 四向入口的花园式布局
- 整体视觉使用 Apple 风格的玻璃质感
- 个人介绍、项目、文章和工具都支持后续持续补充真实内容
