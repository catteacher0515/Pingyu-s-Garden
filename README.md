# Pingyu's Garden

花萍雨的个人数字花园。这个站点优先服务我自己，作为长期维护的个人入口，其次才服务简历展示。

## 页面结构

- `/` 当前为浅色展签式首页入口
- `/profile` 个人介绍
- `/projects` 项目
- `/articles` 文章
- `/tools` 小工具

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 说明

- 当前首页实现是浅色纸感/展签式入口页，入口区由 4 个卡片组成
- 个人介绍、项目、文章和工具页已存在，但内容仍以占位数据为主
- 2026-05-28 已确认新的海报式首页方向，设计稿和实施计划分别在：
  - `docs/superpowers/specs/2026-05-28-poster-home-design.md`
  - `docs/superpowers/plans/2026-05-28-poster-home.md`
- 旧的花园同心圆和玻璃头像中心方案属于历史设计过程，不代表当前实现
