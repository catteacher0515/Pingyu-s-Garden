# 花萍雨数字花园首页海报化设计稿

## 目标

把当前首页从“入口导航页”改成一张更强设计感的海报式封面。

这版首页不再优先服务面试官视角，而是优先服务“我自己会喜欢、会愿意长期保留”的个人站审美。它应该更像一张会被停下来观看的作品海报，而不是一页说明书。

## 设计原则

1. 先做气质，再做信息。
2. 画面优先，功能后置。
3. 保留“数字花园”的主题，但不再用头像或写实人物做中心。
4. 视觉语言要统一，避免回到普通网页、普通作品集或普通导航页。

## 核心方向

首页采用 `黑底 + 红棕 + 手绘/印刷混合` 的海报风格。

参考感来自三件事：
- 黑色舞台感背景
- 中央大展板
- 两侧装饰性边框与手绘痕迹

首页的主体不再是“入口卡片阵列”，而是“海报式主视觉 + 次级内容入口”的组合。

## 页面结构

### 1. 顶部轻导航

顶部保留很轻的站点信息和导航，不抢主视觉。

建议内容：
- 站点名
- about
- work
- connect

导航的作用是提示方向，不承担主要视觉重量。

### 2. 中央海报展板

页面中心保留一块大展板，作为视觉焦点。

展板需要具备这些特征：
- 大面积浅色底
- 红棕色边框或外框
- 轻微纸张纹理或印刷颗粒感
- 与深色背景形成强对比

展板内部不放真人头像。
展板的主视觉应是抽象符号系统，兼具几何秩序和手绘痕迹。

### 3. 两侧装饰边框

左右两侧放非功能性的装饰元素，像海报边饰或手工印章。

可包含：
- 线稿小图标
- 印章感符号
- 垂直排列的装饰块
- 轻微不规则的手绘元素

这些元素的作用是把画面从“网页”推向“作品海报”。

### 4. 次级内容入口

个人介绍、文章、项目、小工具不在首页成为主角，但仍然需要可达。

建议放在海报下方或海报旁的次级区域，以简洁入口方式出现：
- 个人介绍
- 项目
- 文章
- 小工具

入口的视觉重量要低于中央展板，避免和海报主视觉争夺注意力。

## 视觉语言

### 背景

背景主色为黑色或接近黑色的深棕黑。

背景需要带一点层次，不是纯黑平铺：
- 轻微颗粒感
- 柔和渐变
- 局部光晕
- 让中心展板有“被打光”的感觉

### 主色

主色以红棕、陶土色、暖橘棕为主。

它们用于：
- 边框
- 标题
- 关键装饰线条
- 印章感元素

### 字体气质

文字要呈现“印刷感 + 手写感”的混合。

建议策略：
- 大标题：偏印刷感，稳、重、像海报标题
- 辅助文字：允许带一点手写或圆润感
- 导航文字：轻、短、克制

### 纹理与材质

首页必须带材质感，不能是平滑的 AI 风网页。

建议使用：
- 纸张纹理
- 轻微颗粒
- 边缘手绘痕迹
- 模拟油墨/印刷层叠效果

## 内容策略

首页文案要短，像海报标签，不像自我介绍长文。

建议只保留三类文本：
- 一个主标题
- 一个短副标题或宣言
- 少量导航/标签文本

首页不承担完整自我介绍。
完整内容由后续页面承接：
- 个人介绍
- 文章
- 项目
- 小工具

## 交互原则

1. 首屏优先让人“看”，不是先让人“点”。
2. 入口保留，但不能破坏海报感。
3. 动效要克制，优先使用微弱的浮动、渐显、纸面层次变化。
4. 不使用夸张跳动或高频发光效果，避免回到夜景霓虹风。

## 组件分层

### `PosterHero`

负责首页中央海报展板。

职责：
- 承载主标题
- 承载抽象主视觉
- 形成首页视觉中心

### `SideOrnaments`

负责左右装饰性边框与符号。

职责：
- 填充画面边缘
- 加强手工海报感
- 不承载任何核心信息

### `TopNav`

负责顶部站点名与轻导航。

职责：
- 提供基础跳转
- 不抢视觉重点

### `EntryStrip`

负责首页的次级入口区域。

职责：
- 承接个人介绍、项目、文章、小工具
- 作为导航补充
- 保持低视觉权重

## 页面与信息关系

- 首页：展示气质与方向
- 个人介绍页：解释是谁
- 项目页：展示可写进简历的项目
- 文章页：展示公开发布内容
- 小工具页：展示自用工具

首页不再承担完整信息说明，只保留“引导”和“定调”。

## 成功标准

如果这版做对了，用户进入首页时应该先有以下感觉：
- 这不是普通首页
- 这是一个有明确风格的个人作品
- 它更像一张海报，而不是一个功能面板
- 它的设计感足够强，值得长期保留

## 非目标

以下内容不在这次首页设计中优先实现：
- 面试官导向的标准作品集布局
- 头像主视觉
- 大量功能卡片
- 复杂的信息架构说明
- 夜景霓虹风
- 过强的科技感 UI

## 实施约束

1. 保持现有项目的 React + Vite 技术栈。
2. 不引入与主题冲突的通用后台风 UI。
3. 尽量复用现有页面路由结构。
4. 视觉改造优先集中在首页，再逐步延伸到详情页。

## 后续推进顺序

1. 先实现首页海报式主视觉
2. 再统一顶部导航、边框装饰和入口区
3. 然后再把个人介绍、项目、文章、小工具页统一到同一套视觉语言
