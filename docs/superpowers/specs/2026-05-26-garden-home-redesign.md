# 花园首页重构设计稿

## 背景

当前项目已经有了一个花园式首页骨架，但内容和视觉都还停留在早期 MVP 阶段。此次重构不改变“中心花园”的信息组织方式，只重新定义首页的视觉语言、入口关系和内容承载方式。

这个网站的优先级是：

1. 先服务我自己，作为长期使用的个人站
2. 再服务投递简历，作为对外展示的作品集

## 目标

- 保留当前首页的花园结构，不推翻重做
- 把首页升级成“中心头像 + 四向入口”的稳定导航页
- 用 Apple 式玻璃质感统一整体视觉
- 让首页同时兼顾自用、内容沉淀和对外展示

## 信息架构

首页固定展示四个模块：

- 个人介绍
- 项目
- 文章
- 小工具

布局采用中心头像 + 四向环绕的方式：

- 中间：头像
- 上方：个人介绍
- 左侧：项目
- 下方：文章
- 右侧：小工具

首页里的这四个模块都作为固定入口存在，不在首页内折叠隐藏。

## 页面关系

首页负责总览和导航，点击后进入对应详情页：

- 个人介绍 -> 个人主页/简介页
- 项目 -> 项目列表页
- 文章 -> 文章列表页
- 小工具 -> 工具集合页

这意味着首页只承担“入口”和“概览”，详情内容放到各自独立页面中承载。

## 视觉方向

主视觉方向定为：**温室标本馆 + Apple 展示面板感**

关键特征：

- 半透明玻璃卡片
- 柔和模糊背景
- 细边框和浅阴影
- 低饱和绿色、米白、雾蓝作为主色
- 层次清晰，但不过度炫技

这个方向要保留花园感，但让页面看起来更成熟、更稳定、更像一个长期维护的个人作品集。

## 首页布局

首页顶部保留简洁标题区，正文区域使用中心构图：

- 标题区：站点名、简短副标题或状态说明
- 中心区：头像作为视觉锚点
- 四向入口：围绕头像分布，形成明确的导航结构
- 底部：一句轻量提示，引导点击进入详情

布局的核心要求：

- 第一眼能看出这是一个个人站
- 第二眼能看出四个入口的关系
- 第三眼能感受到这是有内容积累的个人作品集

## 详情页策略

每个入口页都保持统一的视觉体系，但内容结构不同：

- 个人介绍页：简介、自我标签、联系方式、能力摘要
- 项目页：适合写进简历的项目列表，优先展示成果和技术点
- 文章页：公开文章列表，突出标题、摘要、发布时间和外链
- 小工具页：自己做的日常工具，突出用途、场景和链接

详情页需要和首页共享同一套玻璃感语言，但内部内容要更明确、更易扫读。

## 交互原则

- 首页入口默认可见，不依赖悬浮层理解结构
- 点击入口进入对应详情页
- 首页可保留轻微动效，例如缓慢浮动、柔和高亮、玻璃反射流动
- 动效必须克制，不抢信息

## 内容策略

内容优先级如下：

1. 先放真实内容，不用假数据充版面
2. 项目页优先展示能写进简历的项目
3. 文章页优先收集公开发布内容
4. 小工具页优先展示你自己确实在用的工具

首页文案需要更像“你的个人入口”，不是通用模板。

## 响应式原则

- 桌面端保持中心花园式布局
- 移动端改为上下排列，仍保留头像作为中心锚点
- 四个入口在小屏下可以从环绕式改为卡片式纵向排列
- 视觉风格保持一致，但要保证可读性和点击可用性

## 验收标准

重构完成后，首页应满足：

- 看起来像一个真正维护中的个人站
- 四个入口清晰、可理解、可点击
- 视觉上明显比当前版本更成熟
- 保留花园主题，但呈现出 Apple 式玻璃质感
- 能支撑后续不断补充真实文章、项目和工具内容
