# `/articles` 文章封面墙设计稿

## 状态

已于 2026-05-30 确认方向，可进入实施计划阶段。

## 目标

把 `/articles` 从旧的蓝黑文字列表页，改造成一个以封面为主视觉的文章展示页。

页面要展示花萍雨已经发布在知乎的文章。每篇文章以“封面 + 标题”的卡片形式出现，点击卡片后跳转到对应知乎文章。

## 参考方向

参考 YouMind 的文章封面展示页：

- 大封面优先
- 黑色粗边框
- 明确的卡片阴影
- 两列网格
- 标题放在封面下方的强对比区域
- hover 时有轻微反馈

但 `/articles` 不能直接照搬 YouMind 的浅色商业站风格。它必须转译到当前 Pingyu's Garden 的 poster-style 视觉系统中。

## 视觉规则

`/articles` 必须和当前首页、`/profile` 保持一致。

必须延续：

- 深黑 / 深棕黑背景
- 暖纸色或黑色卡片结构
- 红棕色强调
- 海报感粗边框
- 轻微纸张或印刷质感
- 克制动效

不要使用：

- 蓝黑玻璃拟态
- 普通博客列表
- 通用 dashboard 卡片
- 过多数据面板

## 页面结构

### 1. 页面头部

保留返回首页入口。

头部内容：

- 标题：`文章`
- 副标题：表达“把学习、工具试用和内容工作流留下来”

头部不做复杂介绍，避免喧宾夺主。

### 2. Article Cover Grid

主体是文章封面网格。

布局规则：

- 桌面端：一行 2 篇文章
- 移动端：一行 1 篇文章
- 每张卡片整体可点击
- 点击后新标签打开知乎文章
- 卡片上半部分为封面图
- 卡片下半部分为固定高度标题区

封面规则：

- 统一 `16:9`
- 使用 `object-cover`
- 即使原图不是 16:9，也要裁切成统一比例
- 不让不同图片比例影响卡片高度

标题区规则：

- 固定高度
- 黑色或接近黑色背景
- 标题使用白色或暖白色
- 标题最多展示 2-3 行
- 超出内容截断或使用 line-clamp
- 不能因为标题长短导致卡片高低不一致

## 数据来源

初版使用真实知乎文章数据，但不做运行时自动抓取。

实施时从知乎文章列表提取最近文章的：

- 标题
- 知乎文章 URL
- 封面图 URL

然后将高清封面下载到项目本地，例如：

- `public/articles/github-w21.jpg`
- `public/articles/mac-switch.jpg`
- `public/articles/ppt-skill.jpg`

文章数据引用本地封面路径，而不是长期直接引用知乎 CDN。

原因：

- 本地资源更稳定
- 避免知乎 CDN 防盗链或链接变化
- 更容易控制封面清晰度
- 部署后加载更可控

## 封面清晰度

已验证知乎文章列表可以拿到封面图。

默认列表图可能只有：

- `480 x 270`
- `480 x 360`

但同一张图可以通过知乎图片后缀拿到高清版本：

- `_qhd` 通常为 `480 x 270`
- `_hd` / `_720w` 通常为 `720 x 405`
- `_1440w` 通常为 `1440 x 810`
- `_r` 或 `_1080w` 最高可到约 `1672 x 941`

初版优先下载 `_1440w` 或 `_r` 版本。如果某张图高清版本不可用，再回退到 `_720w`。

## 初版内容范围

初版展示最近 6 篇知乎文章。

这样桌面端刚好是 3 行，每行 2 张卡片，页面会比较完整。

初版不展示：

- 阅读量
- 点赞数
- 评论数
- 收藏数
- 分类筛选
- 排序
- 分页
- 搜索
- 文章详情页

这些字段后续可以加，但不进入本次范围。

## 数据结构

建议将文章数据从 JSON 改为 TypeScript 数据文件，便于增加封面字段和类型约束。

推荐文件：

- `src/data/articles.ts`

推荐结构：

```ts
export const articles = [
  {
    id: 'github-w21',
    title: 'GitHub 每周精选｜2026 W21',
    cover: '/articles/github-w21.jpg',
    url: 'https://zhuanlan.zhihu.com/p/2042011598328520958',
  },
]
```

如果继续使用 `articles.json` 也可以，但 TypeScript 文件更适合后续扩展。

## 组件计划

建议拆成：

- `ArticlesPage`
  - 页面容器和 header
- `ArticleCoverCard`
  - 单张文章封面卡
- `articles.ts`
  - 文章数据

如有必要，可以新增：

- `src/components/Articles/ArticleCoverCard.tsx`

## 动效

只做轻量动效：

- 卡片入场渐入
- hover 时轻微上浮
- hover 时边框或阴影变化
- 图片可做轻微 scale，但幅度要小

不做：

- 大幅滚动动画
- 自动轮播
- 图片翻转
- 高亮闪烁

## 测试

需要更新 `/articles` 测试。

测试要求：

- `/articles` 可以正常渲染。
- 页面标题 `文章` 出现。
- 至少 6 篇文章卡片出现。
- 每张文章卡片包含封面图。
- 封面图有 alt 文案。
- 卡片链接指向知乎文章，并使用新标签打开。
- 不再出现旧占位文案：
  - `还没有文章，快去写一篇`
  - `文章标题占位`

## 非目标

这次不做：

- 修改首页
- 修改 `/profile`
- 修改 `/projects`
- 修改 `/tools`
- 自动同步知乎文章
- 自动生成封面
- 分类筛选
- 数据指标展示
- 搜索和分页
- 文章详情页

## 成功标准

完成后，第一次进入 `/articles` 的人应该能理解：

- 这是一个以文章封面为主视觉的页面。
- 每张卡片都可以点击进入知乎原文。
- 页面不是普通博客列表，而是和数字花园首页一致的 poster-style 文章墙。
- 卡片高度整齐，封面清晰，标题区域稳定。
