## 一、项目概述

一个以"数字花园"为主题的个人作品集网站，用于展示开源小工具、技术文章、日常记录和零散想法。主要受众是朋友和自己，有趣优先于专业，和 GitHub 的极客风格形成鲜明反差。

**网站名称**：花萍雨的数字花园  
**GitHub 昵称**：花萍雨

---

## 二、视觉风格

- **整体基调**：小清新，绿白渐变背景，圆角卡片，可爱插画元素
- **参考风格**：Bento Grid 布局，类似视频博主 lvyneko 的作品集风格
- **配色**：以绿色系为主（`#e8f5e9` → `#dcedc8`），白色卡片，点缀暖色
- **字体**：正文用无衬线字体，标题可用手写感字体
- **插画元素**：花朵 emoji（🌸🌻🌿🍄）作为核心视觉符号，保持轻盈感

---

## 三、首页结构

### 3.1 花园地图

首页是一张**花园俯视图**，同心圆布局：

```
              🛠️ 小工具
         ┌────────────────┐
    🍄   │                │   📝
  想法   │   🌸 花萍雨    │   文章
         │   05后 · 开发  │
    🍃   │                │
  记录   └────────────────┘
              （未来扩展）
```

- **中心**：花萍雨本人（头像 + 名字 + 简短介绍），永远不变
- **第一圈**：4 个核心板块，均匀分布在中心周围
- **第二圈起**：未来新增板块自然向外生长，花园边界随之扩大

### 3.2 同心圆扩展规则

新增板块 = 在外圈种一朵新花，位置由作者决定。花园没有固定边界，随内容自然生长。初期第二圈用虚线占位符暗示可扩展性。

## 五、交互设计

### 5.1 花朵点击

- **悬停**：花朵轻微放大（scale 1.1），显示板块名称
- **点击**：
  - 工具 / 文章 → 跳转对应独立页面
  - 记录 / 想法 → 原地弹出内容卡片（覆盖层，点击空白处关闭）

### 5.2 原地展开卡片

- 从花朵位置展开，动画自然
- 卡片内展示该板块最新几条内容
- 右上角关闭按钮，点击空白处也可关闭

### 5.3 独立内容页面

- 顶部有返回花园的入口（"← 回到花园"）
- 列表展示该板块所有内容
- 工具页：项目名、简介、GitHub 链接、技术标签
- 文章页：标题、日期、摘要、阅读链接

## 六、技术方案

### 6.1 技术栈

- **框架**：React（Vite 构建）
- **动画**：Framer Motion（花朵交互、卡片展开）
- **样式**：Tailwind CSS（快速实现 Bento 风格）
- **路由**：React Router（首页 ↔ 内容页面）
- **内容管理**：本地 JSON 文件（初期），后期可迁移到 Markdown + 静态生成

### 6.2 项目结构

```
src/
├── components/
│   ├── Garden/          # 花园地图核心组件
│   │   ├── GardenMap.tsx       # 同心圆布局容器
│   │   ├── FlowerNode.tsx      # 单个花朵节点
│   │   └── ContentCard.tsx     # 原地展开卡片
│   ├── pages/
│   │   ├── ToolsPage.tsx       # 工具列表页
│   │   └── ArticlesPage.tsx    # 文章列表页
│   └── layout/
│       └── BackToGarden.tsx    # 返回花园导航
├── data/
│   ├── tools.json       # 工具数据
│   ├── articles.json    # 文章数据
│   ├── notes.json       # 记录数据
│   └── ideas.json       # 想法数据
└── App.tsx
```

### 6.3 部署

- **托管**：Vercel 或 GitHub Pages（静态部署，免费）
- **域名**：可选，初期用平台提供的子域名
