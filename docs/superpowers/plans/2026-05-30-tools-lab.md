# Tools Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `/tools` 从旧列表页改成 poster-style 小工具实验室。

**Architecture:** `ToolsPage` 管理页面布局和分类状态，`ToolCategoryFilter` 渲染分类按钮，`ToolCard` 渲染未来工具卡片，`ToolEmptyState` 渲染空分类。工具数据从 JSON 迁移到 `src/data/tools.ts`，并支持多种工具形态和链接状态。

**Tech Stack:** React 19, React Router 7, Framer Motion, Tailwind CSS 4, Vitest, Testing Library, Vite。
