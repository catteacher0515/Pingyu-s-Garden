# 网站 UI / UX 自查（2026-10-11）

> 2026-10-12 更新：用户决定只做电脑端，下文所有手机端相关的问题不再处理。

视角：当作一个从没存在过的新网站，以第一次来访的陌生人身份审视线上版本 https://pingyu-s-garden.pages.dev （分支 `astro-v2`，提交 `a39bc98` 之后）。证据来自桌面 1440px 和手机 390px 的实际截图。

## 一句话结论

网站现在是"围绕结构"做的，不是"围绕内容和访客"做的：导航有 6 个入口，其中 4 个点进去是空的；视觉上同时存在三套语言（新的深色极简、旧站的红线手绘、知乎封面的花哨配图）；手机端页面被撑宽，文字被裁掉。

## P0：必须先修的问题

> 2026-10-12：第 2–5 项已修复并上线（提交 `bd9a43f`）。

1. ~~**手机端页面被撑宽。**~~（不处理：只做电脑端） 390px 屏幕上，导航栏（6 个链接 + 搜索 + 主题按钮 + GitHub）大约需要 480px，把整页撑宽，正文、按钮、插画右侧都被裁掉。手机需要单独的导航（底部标签栏或折叠菜单）。
2. **空页面把后台说明露给了访客。** 视频页写着"在编辑后台新建第一条吧"，笔记页写着"在 Obsidian 里给笔记加上属性 publish…"。这些是写给站长的话。
3. **6 个导航里 4 个是空的。** 视频 0、笔记 0、教程 0、发发神经 0。首页大字写着"我在做视频"，点进去却什么都没有，第一印象是"没做完"。没有内容的栏目应该自动隐藏，有了第一条再出现。
4. **图片太大。** 单张文章封面最大 2.6MB，首页放映厅一次加载好几张，首屏要下载近 10MB。站点托管在 Cloudflare，国内访问本来就慢一些，会白屏好几秒。应该用 Astro 的图片优化生成 WebP 和多尺寸。
5. **内容要等动画跑完才看得见。** 标题、列表、卡片的初始状态是透明的，靠 GSAP 动画"淡入"。网络慢、脚本没加载完、搜索引擎抓取、社交平台生成链接预览时，看到的都是空白。应该让内容默认可见，动画只做增强。

## 白纸视角：重新想清楚这几件事

### 1. 访客是谁，来了要做什么

最可能的访客：从 B 站、小红书、知乎点进来的观众，以及看简历的人。他们要完成三件事：

- 这个人是谁、靠不靠谱（10 秒内）
- 看看他做过什么、写过什么
- 关注他，或者联系他

现在第三件完全缺失：页脚只有 GitHub，没有 B 站、小红书、知乎、公众号、邮箱。对内容创作者来说，"关注我"应该是全站最重要的转化动作之一。

### 2. 信息架构：6 个入口太多

现在：首页 / 视频 / 图文 / 笔记 / 项目 / 发发神经，并列且权重一样。

建议收成 4 个，按访客心智分组：

- **视频**：主要产出，放第一位
- **写的东西**：教程、笔记、旧文章合在一起，内部用筛选区分
- **做的东西**：项目和工具
- **关于我**：独立页面，包含介绍、联系方式、各平台链接；「发发神经」作为关于页里的一个入口，或放页脚，它是私人角落，不该和作品并列

### 3. 首页

- 第一屏应该给"真实的证据"：一段自己出镜或作品剪辑的视频循环，或一张真实照片，而不是旧站海报里裁出来的插画。
- 放映厅适合"有足够多视觉作品"的时候。现在里面是知乎封面和工具截图，信息密集、每 5 秒自动切走，访客来不及看。内容少时，一个静态的"精选 3 件"网格更有效；等视频超过 3 条再启用放映厅。
- 加一个明确的"关注我"区块（各平台按钮 + 粉丝数或简介）。

### 4. 视觉：统一成一套语言

当前三套视觉打架：

- 深色极简 + 珊瑚色强调（新）
- 红线手绘插画和方框图标（旧站遗留）
- 知乎封面图（每张风格都不同，颜色很杂）

建议：

- 定下一个新的视觉识别：主色、字体、图形语言。旧站的红线手绘要么彻底拿掉，要么按新风格重画，不要原样沿用。
- 封面统一模板：所有卡片缩略图用同一比例、同一种标题样式；没有好封面的用统一的文字封面，不用那张手绘方框图标兜底。
- 主题默认跟随系统（`prefers-color-scheme`），而不是强制深色。最早觉得"压抑"的正是深色底。
- 去掉装饰性的英文小标题（NOW SHOWING、MURMURS、ABOUT 等），访客是中文用户，这些来自旧站的双语装饰。

### 5. 每种内容用适合它的版式

- 现在所有列表页都用"左侧边栏 + 右侧目录 + 底部浮动搜索框"的文档站版式。它适合长篇阅读（教程、笔记），但用在视频和项目上是负担：视频页只有一个分组，侧边栏和目录都是空转；浮动搜索框和顶部的搜索重复，在手机上还会挡住内容。
- 视频、项目：画廊式网格，突出缩略图，没有侧边栏。
- 教程、笔记：保留文档式阅读版式。
- 发发神经：时间线，保持现状。

### 6. 细节

- 搜索按钮上的 `⌘K` 在手机和 Windows 上没意义，应按设备显示或只显示图标。
- 四级、六级工具站用了同一张封面，并排出现像是重复 bug，可以合并成一个项目。
- 项目按"可访问 / 自用中 / 实验中 / 已归档"分组，这是站长视角。访客更关心"这能帮我做什么"，建议按用途分组，状态做成小标签。
- 没有独立的"关于我"页面，"关于我"链接只是跳到首页中间。
- 轮播的拖拽、自动播放对键盘和读屏用户不友好；自动播放应在鼠标悬停或聚焦时暂停。

## 建议的推进顺序

1. 修 P0（空栏目隐藏与访客友好的空状态、图片优化、内容默认可见）。这些和视觉方向无关，可以直接做。
2. 定信息架构（4 个入口 + 关于我页面 + 关注我）。
3. 用可交互原型探索新的视觉识别（2–3 个方向），定下来后统一替换旧站元素。
4. 按内容类型调整版式（视频、项目改画廊；教程、笔记保留文档式）。
