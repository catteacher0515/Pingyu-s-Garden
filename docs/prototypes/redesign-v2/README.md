# 翻新原型 v2（2026-10-07）

单文件可交互原型，浏览器直接打开 `index.html` 即可，不依赖构建。GSAP 放在 `assets/`，图片直接引用仓库里的 `public/` 和 `src/assets/poster/`，所以不要把这个文件夹单独挪走。

## 方向

- 起因：旧的海报风（深棕黑底 + 红棕装饰）太压抑。
- 参考：[GSAP Showcase](https://gsap.com/showcase/)（首页放映厅轮播、跑马灯、大箭头）和 [HyperFrames Showcase](https://hyperframes.heygen.com/showcase)（左侧分组导航 + 右侧本页目录的文档站布局、⌘K 搜索、底部浮动搜索框）。要学的是 UI/UX 和动效，不只是配色。
- 首页主角是「我这个人」：第一屏大字自我介绍 + 轮换动词 + 手绘插画；第二屏「最近在做」放映厅；第三屏四条内容线。
- 四类内容：视频、项目、文章、周刊。放映厅里每类内容有独立卡片模板（视频整卡播放、项目套浏览器框、文章标题 + 摘要 + 完整封面、周刊大号期数）。
- 所有内容收在一个 `content` 列表里，`featured: true` 的自动进放映厅。
- 列表页合并为「作品」（视频 + 项目）和「文字」（文章 + 周刊）。
- 支持深色 / 浅色切换，尚未决定默认用哪个。

## 状态

- 只是原型，尚未迁入 `src/`，线上站点仍是旧海报风。
- 视频卡片是「示例占位」；项目「截图」暂用文章封面；文章摘要是按标题临时写的，正式版需换成真实素材和文案。
- 用户反馈（2026-10-07）：动效明显比旧版好，但还有不少地方要改，具体修改点待下次会话再定。
