# 首次 push 到 Fork 失败：仓库名、443 超时、403 权限

## 卡在哪

把换成 RustFS 的改动推到自己的 Fork，`git push -u origin main` 连续失败三次，每次报错都不一样。

![](/media/notes/24591f266e.webp)

## 我怎么定位的

1. **第一次：`Repository not found`**

	![](/media/notes/aab7de2410.webp)

	- 报错直说：远程仓库不存在
	- 以为是没点 Fork，其实已经 Fork 了，但 Fork 出来的仓库叫 `ai-picture-editor`
	- 原因：作者仓库真名是 `ai-picture-editor`，`ai-retouch-agent` 是旧名，访问会 301 跳转；本地文件夹沿用了旧名，`origin` 地址照着旧名写，指向了不存在的仓库

	![](/media/notes/e56b529125.webp)

	- → `git remote set-url origin` 改成真名
2. **第二次：`Failed to connect to github.com port 443 after 75003 ms`**

	![](/media/notes/aa4ddc12a6.webp)

	- 443 是 HTTPS 端口，连了 75 秒没连上 → 连接超时，网络没通
	- 浏览器能开 GitHub 是因为它读系统代理；git 不读，直连被墙
	- → 给 git 单独配代理：`git config --global http.https://github.com.proxy http://127.0.0.1:7892`
3. **第三次：`Permission ... denied to catteacher0515`，403**

	![](/media/notes/b400af6643.webp)

	- 身份是对的（GitHub 认出了 `catteacher0515`），但 403 = 知道你是谁、你没权限
	- 钥匙串里存的是 fine-grained token（`github_pat_` 开头），只授权了创建时勾选的仓库，新 Fork 不在范围内
	- SSH 密钥已配好，`ssh -T git@github.com` 返回 `Hi catteacher0515!`，模拟推送能成功

## 根因 & 修复

> **根因**
> 三层叠加：① origin 用了仓库旧名；② git 不走系统代理，HTTPS 连不上 GitHub；③ HTTPS 用的细粒度令牌没有授权这个新仓库。

| 问题 | 修复 |
|---|---|
| 仓库名不对 | `origin` 改成 `ai-picture-editor` |
| 443 超时 | git 单独配 GitHub 代理（改用 SSH 后不再依赖） |
| 403 无权限 | `origin` 改用 SSH：`git@github.com:catteacher0515/ai-picture-editor.git` |
