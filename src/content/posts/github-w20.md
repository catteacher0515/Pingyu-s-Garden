### 1. BongoCat

项目名：BongoCat-Desktop

GitHub 仓库地址： https://github.com/lucasfrre/BongoCat-Desktop

相信应该是有部分的朋友是刷到过这只网红 BongoCat 的，毕竟谁能抵抗在桌面上养一只跟着你操作一起摇摆的小猫呢~

这个 GitHub 仓库是最近新提交的的，大概一周左右的时间，但 Star 数增长的很快，已经到 445 了，足以可见大家对于 BongoCat 的喜爱了

所以如果你觉得桌面有些冷清，想要一个能够实时反馈你敲键盘，移动鼠标和音乐节奏的小可爱，那它会适合你的

不过这里，我需要特别提一点，就是这个 GitHub 仓库只提供了 Windows 的版本，并没有 mac 的版本，所以如果你是 mac 用户的话，请移步到这个仓库 https://github.com/Gamma-Software/BongoCat-mac

![](/media/articles/github-w20/0e8a97bb3b.webp)

### 2. LifeManga

项目名：LifeManga

GitHub 仓库地址： https://github.com/iam567/LifeManga

你有没有想过，随手拍的一张生活照——比如在××街吃牛肉面、雪夜里散步——能一键变成日式漫画？这就是 LifeManga 在做的事。

作者说这是“闲着没事随手写的”，但成品一点都不随便：它把 OpenAI 最新的图像生成能力塞进了一个 iOS App，让你拍照、选风格、加气泡文字，就能生成真正的漫画分镜。

更妙的是，它还内置了“角色库”和“故事模式”——你可以从真人照片生成角色设定稿，再让 AI 帮你写剧本、画多格漫画。

适合想把自己的日常漫画化，又不想学绘画的人

需要注意的事这个项目是 iOS 17+ 的应用，需要有 mac 和 iPhone 的朋友才能使用，门槛会高一些

![](/media/articles/github-w20/f00655c505.webp)

### 3. cell-architecture-studio

项目名：cell-architecture-studio

GitHub 仓库地址：[https://github.com/cclank/cell-architecture-studio](https://github.com/cclank/cell-architecture-studio)

这是一个能把细胞结构用 3D 方式直观展现的项目，有七种细胞的可视化浏览，如下：

- 白细胞
- 神经元
- 植物细胞
- 上皮细胞
- 细菌细胞
- 动物细胞
- 肌肉细胞

在左侧可以切换细胞类型；中间看 3D 结构，既然是 3D，自然是可以旋转看各个角度的；右侧会展示细胞器的说明；有不错的交互体验

如果你是想要做生物教育，科普展示，课堂展示的朋友，亦或者是对于细胞可视化感兴趣的朋友，我会向你推荐这个仓库，还是蛮好玩的

但如果是为了科研建模或者仿真之类的就不是很推荐了

![](/media/articles/github-w20/30878bbe60.webp)

### 4. CodexSaver

项目名：CodexSaver

GitHub 仓库地址：[https://github.com/fendouai/CodexSaver](https://github.com/fendouai/CodexSaver)

如果你已经在用 Codex，但又觉得很多简单任务其实没必要每次都消耗高成本模型，可以看看 CodexSaver。

它主要解决的是一个很实际的问题：把 "解释代码、扫仓库、写文档、补测试" 这类不是那么依赖高成本模型的工作分出去，把真正需要经验和判断的部分继续留给更贵的模型。这样既能保留 Codex 的质量，又能把整体使用成本压下来一些。

所以如果你日常已经在使用 Codex 了，想要进一步来优化成本；或者是小型团队里经常有大量解释代码，整理，测试的这类工作的朋友，那么这个仓库是值得你试一试的
