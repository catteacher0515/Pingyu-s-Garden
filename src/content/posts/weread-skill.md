你在阅读的时候是否也会遇到这些问题？

- 不知道读什么书
- 想要分析自己的阅读情况，却无从下手
- 读过一些内容，但在想找的时候却找不到

那么最近新出的微信读书 skill 大概率会帮助你，下面我们开始吧

### 安装和配置

首先微信读书 skill 对应的链接如下： https://weread.qq.com/r/weread-skills

安装很简单直接把 "复制 Skill 安装指令" 的内容给任意一个能给支持 Skill 的 AI Agent 即可，我用的是 Codex

```
npx skills add Tencent/WeChatReading -g
```

配置的话和 Codex 这样说一下就会去自行安装了

```
这是 API Key：××，请自动完成配置和授权 
```

到这里恭喜你成功的安装和配置好微信读书 skill 了

![](/media/articles/weread-skill/3db4860b2d.webp)

### 能想起来一点但不多

你是不是也遇到过这种情况，之前有读过一些内容，但只有一个模糊的印象，遇到一些事情，想要找到原来看过这部分内容，通过微信读书的基础搜索功能却搜索不到

这种时候，传统的读书方式就会很无力。记忆是散的，笔记是散的，书也是散的，最后只能在一堆信息里反复翻找，越找越确定自己记错了

比如我之前看过一篇克服拖延症的方法，但具体是哪一本、哪一章、哪一句，已经完全想不起来了，只有 "我好像在某本书里看到过解决拖延的方法" 这个模糊的印象，那能不能找到呢？

答案是大概率可以的，你可以将刚才模糊的想法 Codex，然后通过调用微信读书 skill，来实现范围的缩小，从模糊的关键词变成候选书，再从候选书缩小到章节，最后定位到自己所需要的内容

它并没有让你成为一个过目不忘的人，但确实能让你在已经忘掉大半的情况下，仍然有机会通过一点点残存的记忆找到自己所需要的内容
